## Side Project: Autism Support Tools

I also build local-first tools for autistic children, families, and caregivers. This is a personal side project focused on calm interaction, communication support, offline privacy, and accessible play.

- [BrightVoice AAC](https://github.com/rahulrainarr/brightvoice-aac) — offline AAC starter app for Windows and Android with visual communication cards, sentence building, and caregiver personalization
