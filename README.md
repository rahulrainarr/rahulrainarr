## Autism Support tools

Featured repository: [Autism Support tools](https://github.com/rahulrainarr/digitial-puzzle/tree/main/autism-support-tools)

Autism Support tools is a local-first collection of learning, puzzle, and AAC support apps designed for autistic children and caregivers. The goal is to help children learn while playing, communicate through visual supports, and stay engaged through predictable low-distraction screens.

The collection includes:

- **BrightSteps Puzzle Time** - Android and Windows puzzle app with calm feedback, adaptive local progress, and play-based learning activities.
- **BrightVoice AAC** - offline AAC starter board for Windows with visual communication cards, sentence builder, core words, and caregiver personalization.
- **Digital Puzzle** - browser puzzle activity retained as a lightweight play-and-learning prototype.

Design and testing focus:

- Low-distraction, predictable UI patterns for autistic children
- Large clear choices and touch-friendly interaction
- Gentle encouragement instead of harsh error cues
- Offline-first privacy with local settings/progress
- No ads, analytics, login, or external JavaScript in the support apps

Note: these are engagement and communication support tools, not medical advice or substitutes for individualized guidance from caregivers, educators, therapists, or speech-language professionals.
